
# CareerPath Mobile App

## Project Description
CareerPath is a mobile-friendly career exploration
application that helps students, graduates, and job
seekers research occupations and compare salaries.

## Target Audience
- College students
- Recent graduates
- Job seekers
- Adults considering career changes

## Main Features
- Displays 20 occupations
- Searches careers by job title
- Filters careers by category
- Sorts careers by median annual wage
- Displays detailed employment and wage information
- Responsive design for mobile devices

## Dataset
Source: New York State Open Data
Dataset: Occupational Employment and Wage Statistics

CSV source:
https://data.ny.gov/api/v3/views/gkgz-nw24/export.csv?accessType=DOWNLOAD

The project uses 20 selected occupational records.

## How to Run
1. Open the project in Visual Studio Code.
2. Start a local web server.
3. Open the app in a browser.
4. Use the search and filter controls.
5. Open Chrome DevTools to test mobile layouts.
